# Kalibrasi lapangan

Posisi ring, gawang, dan garis ditandai sekali oleh Coach saat setup (klik titik, mirip klik 4 sudut di repo badminton). Targetnya tidak bergerak, jadi model cukup fokus ke bola. Datanya disimpan backend di device_sessions.calibration dan dibawa ke detektor lewat SegmentContext.

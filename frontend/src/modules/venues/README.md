# Frontend modul venues

Backend: `backend/src/modules/venues/README.md`. Hanya tampilan, tanpa aturan bisnis.

Halaman:

- `/venues`: Cari lapangan
- `/venues/[id]`: Detail lapangan
- `/owner/venues`: Lapangan saya
- `/owner/venues/new`: Daftarkan lapangan
- `/owner/venues/[id]/schedule`: Atur jadwal dan harga
- `/admin/approvals/venues`: Persetujuan lapangan (admin)
